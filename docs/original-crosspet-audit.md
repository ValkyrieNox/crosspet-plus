# Windows 原版功能保留与本机配置

基线是仓库引入的 CrossPet **1.3.10**，提交 `8954eb8f7f69fcfb8d35e9deceeb78e10c804402`。本报告不把其他上游版本的新功能算作已经引入。

## 实现核对

`python3 scripts/audit-crosspet-original.py` 核对了 901 个原始文件：22 个网页文件、39 个 Windows 源文件和项目文件、808 个角色资源、19 个接入文件、13 个工具文件。没有缺失原始文件。

- 任务、动画、点击、拖动反馈、彩蛋、多桌宠剧情使用原版 `app/web/`。`index.html` 只保留 Mac 后台断开时的清理接口；移除该接口后与基线完全一致。其余 21 个网页文件完全一致。
- 808 个角色资源、13 个原始工具文件完全一致。
- Windows 主体仍是原生 WPF + WebView2。原版菜单、角色设置、贴边、前台跟随、额度、快捷键、多桌宠窗口和资源管理均在。接线处只添加后台启动、会话合并、功能菜单、统一应用标识和本仓库更新地址。
- 三处原版接入适配仅为 Mac 启动正确的 Plus 应用；Windows 的原版事件处理逻辑未被替换。
- 不存在 `collaboration.js`、自定义子代理动画档位、数量角标或额外动画优先级。

## 验证范围

本轮已通过原版源码保留核对、60 项真实页面脚本检查、原有 Node 功能检查、130 项 Python 检查（其中 2 项按环境跳过）及 Windows 纯逻辑检查。托盘资源检查在允许其启动 Node 子进程后通过；最初的失败来自沙箱禁止子进程。

这些检查覆盖原实现及接线，不能代替每个第三方客户端登录后的实机操作。没有为验证而模拟鼠标、展开托盘、切换前台，或人为触发真实审批。Codex hook 信任、第三方账号额度、未安装客户端和已关机远端分别保留其真实限制。

安装完成后，再用以下命令逐文件核对安装资源：

```sh
python3 scripts/audit-crosspet-original.py --installed-root '/mnt/c/Users/你的Windows用户名/AppData/Local/Programs/CrossPet'
```

安装器备份配置，核对复制的文件数量、大小和 SHA-256，并保留上一个安装目录；个人配置和备份不提交仓库。
