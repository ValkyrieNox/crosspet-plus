修复 Windows 开机启动状态与设置开关不一致。

- 原生设置同时检查启动命令和 Windows 的启用状态。任务管理器禁用启动项后，设置不会继续显示为开启；主动开启时只重新启用 CrossPet 自己的启动项。
- 任务与审批设置中的“开机自启”现在调用原生 CrossPet 设置入口并核对结果，启动的是唯一的 CrossPet 主程序。查询和修改不会新建桌宠、移动已有桌宠或切换前台。
- Windows 后台启动和重新打开设置时重新读取系统状态；操作失败会返回错误，避免只保存一个无效开关。
- 启用后会等待并复查状态。启动管理软件立即撤销启用时会返回失败；安装回执记录真实启动状态，桌宠本身仍可正常运行。
- 升级时保存启动项与 Windows 启用状态备份，尊重已禁用的状态；其他角色、动作、连接、钩子和审批设置保留。
- 安装目录遇到短暂文件占用时有界等待；持续占用则回退，保留旧版和完整配置备份。

Windows 解压后运行 `install.cmd`。macOS 行为沿用 plus.8；本次仅修复 Windows 的启动接线。
